Captured from the packaged macOS `0.1.0-alpha.4` app with a separate synthetic
eight-input show. Generic channel names and checklist state were configured
through the real API; readings come from the app's synthetic audio engine.

interface without fabricated native window controls. The original PNGs are kept
alongside lossless WebPs; captures were not upscaled or retouched.
